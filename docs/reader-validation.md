# Reader: επαλήθευση εκκίνησης και συμβατότητας

Βάση: `main` / `c46b5921d7b0a7a36d60296a898fe74b1a58ba32`, έκδοση 3.1.2.
Δεν αλλάζουν βιβλία, εκδοτικά δεδομένα, Worker ή secrets.
Τα διπλά page turns έχουν επιβεβαιωθεί ως λυμένα από τον χρήστη και δεν καταγράφονται ως ανοικτό πρόβλημα.

## Επιβεβαιωμένες αιτίες και παρεμβάσεις

Στο ενσωματωμένο `pdl-reader-shell` του `index.html`, το `pdlPaginate()` καλούσε τον legacy paginator όσο το `PDL_HYPH` δεν ήταν έτοιμο. Οι διαδοχικές ειδοποιήσεις fonts/patterns προκαλούσαν πλήρεις προσωρινές σελιδοποιήσεις πριν από την προοδευτική διάταξη. Η νέα διαδρομή περιμένει τα patterns, χωρίς OPF rebuild ή εγγραφή προσωρινής θέσης, και μετά ξεκινά την υπάρχουσα προοδευτική μηχανή. Η αναμονή των pattern promises περιορίζεται στα 3 s. Αποτυχία ή timeout ενεργοποιεί το υπάρχον legacy fallback. Αυτό δεν αποτελεί συνολικό όριο για τη λήψη του αρχικού συγχρονικού loader script.

Τρία ανοίγματα του πραγματικού πολυτονικού βιβλίου ανά έκδοση, σε νέα Chromium contexts, localhost, viewport 390×844, χωρίς CPU/network throttling:

| Διάμεσος | Βάση | Αλλαγή |
| --- | ---: | ---: |
| Legacy κλήσεις πριν την προοδευτική διάταξη | 2 | 0 |
| Συνολική εργασία legacy | 931 ms | 0 ms |
| Πρώτο render κειμένου | 468 ms | 262 ms |
| Πρώτο render επαληθευμένων σελίδων | 1.238 ms | 262 ms |
| OPF builds στην εκκίνηση | 2 | 1 |

Μετρήθηκαν κλήσεις rendering, όχι browser paint metrics ή απόκριση φυσικού κινητού. Οι τρεις δοκιμές τεκμηριώνουν την αφαίρεση της περιττής εργασίας· δεν αποτελούν υπόσχεση χρόνου φόρτωσης.

Στα mobile controls, οι `resize`/`scroll` listeners του `parent.visualViewport` κρατούσαν το κλειστό iframe στη μνήμη. Σε δέκα διαδοχικά ανοίγματα/κλεισίματα και forced GC, πριν τη διόρθωση τα documents αυξήθηκαν 8→26, τα nodes 1.211→9.086 και οι listeners 34→70. Με αποδέσμευση στο `pagehide` και επανασύνδεση σε persisted `pageshow`, έμειναν σταθερά στα 3 documents, 315 nodes και 30 listeners. Το νέο memory regression αποτυγχάνει στη βάση με retained documents στον τρίτο κύκλο και επιτυγχάνει μετά τη διόρθωση. Η JS heap αυξήθηκε ακόμα 9,91→12,81 MiB: η αποδέσμευση DOM αποδεικνύεται, όχι η απουσία κάθε πιθανής διαρροής ή engine cache. Δεν επιβάλλεται αυθαίρετο όριο heap στα tests.

Αφαιρέθηκαν μόνο ο ανενεργός `pdlTurnBusy` (δεν οριζόταν ποτέ true), οι αντίστοιχοι νεκροί έλεγχοι και το αχρησιμοποίητο alias `pdlBaseMeasure`. Οι πραγματικές ασφάλειες animation/gesture του OPF παραμένουν.

Η αρχική mobile κατάσταση `immersive` ορίζεται αμέσως μετά το άνοιγμα του body, πριν από το markup των χειριστηρίων. Πριν τη μεταφορά αυτή, υπήρχε ευκαιρία για paint των πάνω/κάτω κουμπιών πριν εκτελεστεί το μεταγενέστερο initialization. Το mobile browser test εισάγει parser gate πριν από το κύριο Reader script και δειγματοληπτεί κάθε animation frame μέχρι την επαληθευμένη προβολή. Στην προηγούμενη έκδοση εντοπίζει και τις δύο μπάρες ως ορατές· μετά τη διόρθωση μένουν κρυφές σε 320/390 px και εμφανίζονται κανονικά με διπλό tap.

## Αυτοματοποιημένοι έλεγχοι

- `npm test`: υπάρχοντα regression tests και διαδρομές pending/ready/failure της σελιδοποίησης.
- `npm run test:browser`: πλήρες υπάρχον Chromium suite, με επιπλέον startup και memory tests.
- `hyphenation-startup-browser.mjs`: κανονική εκκίνηση, καθυστερημένο WASM, page-only saved progress και πρόωρο κλείσιμο, timeout, αποτυχία loader, ρητά απενεργοποιημένο grid. Ελέγχει επιτυχή πλοήγηση που ζητήθηκε κατά την αναμονή, source text/δομές και fallback χωρίς μπλοκάρισμα. `PDL_STARTUP_BENCHMARK=1` εκτυπώνει τρεις συγκρίσιμες μετρήσεις χωρίς assertions που προϋποθέτουν τη βελτίωση.
- `reader-memory-browser.mjs`: έξι πραγματικά ανοίγματα/πλήρεις σελιδοποιήσεις/κλεισίματα, garbage collection και σταθερότητα documents/nodes/listeners μετά το warmup.
- `mobile-controls-browser.mjs`: ελέγχει επιπλέον επανασύνδεση μετά από συνθετικό persisted pagehide/pageshow και κατόπιν αλλαγή γονικού visual viewport.
- `npm run test:compat`: ξεχωριστά Chromium, Firefox και WebKit στο CI Ubuntu 24.04. Πραγματικό `el-polyton`, πλήρης source/grapheme integrity, αλλαγή Calibri/Carlito και 130%, περιστροφή viewport με διατήρηση source θέσης, αναζήτηση αποσυντεθειμένου ελληνικού Unicode και αποστρόφων, animated page turn.

Το τοπικό Chromium λειτουργεί. Τα τοπικά Firefox/WebKit δεν μπόρεσαν να εκκινήσουν λόγω sandbox/ελλιπών system libraries. Τα αποτελέσματα των τριών engines πρέπει να διαβάζονται από το συγκεκριμένο CI run του PR, όχι να θεωρούνται PASS από την ύπαρξη του workflow. Playwright WebKit δεν ισοδυναμεί με φυσικό Safari/iOS και Linux Carlito δεν αποδεικνύει native Calibri σε Windows.

## Χειροκίνητη δοκιμή σε φυσικές συσκευές

Σε τουλάχιστον ένα πραγματικό Android/Chrome και ένα iPhone/Safari:

1. Ανοίξτε το πολυτονικό βιβλίο σε Barnebok και Calibri, 100% και 130%. Δοκιμάστε swipe και κουμπιά όσο προχωρά η σελιδοποίηση, μετά περιστροφή portrait/landscape. Ελέγξτε συνέχεια κειμένου, υπερχείλιση και θέση ανάγνωσης.
2. Με διπλό tap ανοίξτε χειριστήρια. Αναζητήστε συχνή λέξη, μετακινηθείτε σε ευρήματα κοντά στην τελευταία γραμμή και ανοίξτε/κλείστε το πραγματικό πληκτρολόγιο. Το ενεργό εύρημα και το πεδίο αναζήτησης πρέπει να παραμένουν ορατά.
3. Προσθέστε σελιδοδείκτη με σύντομο πάτημα, ανοίξτε τη λίστα με παρατεταμένο, ακυρώστε πάτημα με μετακίνηση. Επιστρέψτε στη βιβλιοθήκη και ξανανοίξτε δέκα φορές.
4. Αφήστε το tab στο παρασκήνιο, επιστρέψτε, αλλάξτε μέγεθος και ξανανοίξτε το βιβλίο. Επιβεβαιώστε αποθηκευμένη source θέση και λειτουργία αναζήτησης/χειριστηρίων.
5. Σε Windows με εγκατεστημένη Calibri ελέγξτε και τη native γραμματοσειρά. Χωρίς Calibri επιβεβαιώστε Carlito.

Για εύρημα σημειώστε συσκευή, OS/browser version, βιβλίο/κεφάλαιο, font/μέγεθος, προσανατολισμό και βήματα αναπαραγωγής. Φυσικές συσκευές και συμπεριφορά πραγματικού πληκτρολογίου παραμένουν προς επιβεβαίωση χρήστη.

## Επόμενες προτεραιότητες μετά τη δημόσια ενσωμάτωση

Η δημόσια ενσωμάτωση ολοκληρώθηκε στο `afb4e453af3267301c18a6b394e8079e6e08af7e`. Τα [build/regression και compatibility jobs](https://github.com/ksaefos/pontian-digital-library/actions/runs/43920118957) και η [δημοσίευση Pages](https://github.com/ksaefos/pontian-digital-library/actions/runs/43920118223) πέρασαν. Το OpenPageFlip, η προοδευτική σελιδοποίηση, η πλήρωση στο 130%, η θέση ανάγνωσης και τα νέα χειριστήρια έχουν αυτοματοποιημένη κάλυψη. Τα διπλά page turns παραμένουν επιβεβαιωμένα ως λυμένα.

1. **Φυσικές συσκευές:** ολοκλήρωση του παραπάνω checklist σε Android/Chrome, iPhone/Safari και Windows με native Calibri. Οι γενικές επιβεβαιώσεις χρήσης και τα Playwright tests δεν αποτελούν καταγραφή κάθε συνδυασμού πραγματικού πληκτρολογίου, περιστροφής και επαναφοράς από παρασκήνιο.
2. **Υπολειπόμενη αύξηση JS heap:** μετρήσεις περισσότερων κύκλων και heap snapshots για να φανεί αν η αύξηση σταθεροποιείται ή αν υπάρχουν συγκεκριμένα retainers. Η διαρροή των κλειστών Reader DOM έχει διορθωθεί· η υπόλοιπη αύξηση δεν έχει ακόμη αποδοθεί σε νέα διαρροή.
3. **Αργό δίκτυο και offline επαναφορά:** έλεγχος πρώτης επίσκεψης χωρίς cache, καθυστέρησης των αρχικών scripts, επόμενης offline επίσκεψης και ενημέρωσης εγκατεστημένου PWA. Το όριο 3 s αφορά τα pattern promises, όχι ολόκληρη τη φόρτωση του αρχικού loader. Αυτοί είναι επιπλέον έλεγχοι ανθεκτικότητας, όχι ήδη επιβεβαιωμένα νέα σφάλματα.

Οι «Οδηγίες ανάγνωσης» βρίσκονται στο modal της αρχικής βιβλιοθήκης (`#pdl-help-dialog`). Πρέπει να ενημερώνονται μαζί με κάθε αλλαγή χειριστηρίων, ιδίως όταν διαφέρουν κινητό και υπολογιστής. Οδηγίες για συλλαβισμό ή άλλες εκδοτικές επιλογές δεν εμφανίζονται ως ρυθμίσεις του αναγνώστη.
