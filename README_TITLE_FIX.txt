# Pontian Digital Library v2.0.5 — διόρθωση τίτλων

Αντικατάστησε στο GitHub **μόνο** τα `index.html` και `sw.js`.

- Η έκδοση που εμφανίζεται στον τίτλο της αρχικής βιβλιοθήκης ορίζεται πλέον κεντρικά από τη σταθερά `PDL_APP_VERSION`.
- Ο τίτλος παραμένει σωστός και κατά την επιστροφή από την ανάγνωση βιβλίου στη βιβλιοθήκη.
- Ανανέωση service worker cache, ώστε να εγκατασταθεί το νέο HTML στο PWA.
- Οι παλιοί αριθμοί έκδοσης σε σχόλια και αναγνωριστικά παραμένουν σκόπιμα αμετάβλητοι.
- **ΜΗΝ** αντικαταστήσεις το `library-data.json`. Το αρχείο αυτό δεν περιλαμβάνεται στο ZIP και τα δημοσιευμένα δεδομένα δεν επηρεάζονται.

Σημείωση: Αν έχεις ήδη αποθηκευμένο σελιδοδείκτη στον Chrome/Edge με όνομα v2.0.4, ο browser δεν μετονομάζει αυτόματα τον υπάρχοντα σελιδοδείκτη. Μετονόμασέ τον ή δημιούργησε νέο αφού ανοίξεις την ανανεωμένη σελίδα.
