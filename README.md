# Pontian Digital Library v1.5.8

Διορθωμένη βάση PWA με PDL_HYPH. Διόρθωση του placeholder θέσης ανάγνωσης σε μία εμφάνιση ανά embedded reader, ώστε να λειτουργεί η επαναφορά θέσης. Περιλαμβάνει καθαρή αντιγραφή χωρίς U+00AD.

Ανέβασε στο GitHub Pages τα `index.html` και `sw.js` από αυτό το πακέτο. Τα αρχεία `manifest.webmanifest` και `icons/` δεν χρειάζονται αλλαγές.
