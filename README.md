# Pontian Digital Library v1.5.7

Περιέχει τον τροποποιημένο reader με το `PDL_HYPH` από τα αρχεία που επισυνάφθηκαν στη συζήτηση.

- Διατηρεί τις βιβλιοθήκες «Η Σωνίτσα» και «Το ψωμίν».
- Αφαιρεί τα αόρατα U+00AD κατά την αντιγραφή επιλεγμένου κειμένου από το βιβλίο.
- Ασφαλής αρχικοποίηση του `__INITIAL_POSITION__` όταν ο reader δοκιμάζεται μεμονωμένα.
- PWA cache `pontian-digital-library-v1.5.7`.

Αντικαταστήστε στο GitHub Pages τα `index.html` και `sw.js`. Τα υπόλοιπα αρχεία μπορούν να παραμείνουν εφόσον είναι ίδια με το πακέτο σας.

Σημείωση: η λειτουργική ορθότητα του χειροκίνητου συλλαβισμού σε όλες τις ποντιακές λέξεις απαιτεί φιλολογικό έλεγχο.
