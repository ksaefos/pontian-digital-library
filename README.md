# Pontian Digital Library — PWA v1.5.0

## Περιεχόμενα
- `index.html`: αρχική βιβλιοθήκη και τα δύο έργα του Γεωργίου Ζερζελίδη, ενσωματωμένα σε ένα αρχείο.
- `manifest.webmanifest`: όνομα/εικονίδια/κατάσταση standalone.
- `sw.js`: offline cache της εφαρμογής μετά την πρώτη επιτυχή σύνδεση.
- `icons/icon-192.png`, `icons/icon-512.png`: παραλλαγές του δοθέντος λογότυπου.

## Ανάρτηση (GitHub Pages)
1. Δημιούργησε νέο GitHub repository, π.χ. `pontian-digital-library`.
2. Ανέβασε **τα περιεχόμενα** αυτού του φακέλου στη ρίζα του repository (ή στον φάκελο που θα δημοσιεύεται μέσω Pages).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Άνοιξε την HTTPS διεύθυνση GitHub Pages (μορφή `https://username.github.io/pontian-digital-library/`).
5. Άνοιξε την εφαρμογή σε Android Chrome. Όταν διατεθεί το «Εγκατάσταση εφαρμογής», πάτησέ το ή επέλεξε την εντολή εγκατάστασης από το μενού Chrome.
6. Άνοιξέ την **μία φορά online**· έπειτα δοκίμασε offline λειτουργία (λειτουργία πτήσης).

## Σημαντικά
- Η εγκατάσταση PWA απαιτεί HTTPS (ή localhost): το `file://index.html` δεν ενεργοποιεί Service Worker και δεν αρκεί για εγκατάσταση.
- Οι τέσσερις ενσωματωμένες γραμματοσειρές διατηρούνται. Ο κληρονομημένος reader περιλαμβάνει και αναφορές σε Google Fonts· όταν είσαι offline μπορεί να μην φορτώσουν, αλλά οι ενσωματωμένες γραμματοσειρές δεν εξαρτώνται από αυτές.
- Τα δύο έργα παραμένουν απομονωμένοι readers (`iframe srcdoc`), ακριβώς όπως στη v1.4.4. Δεν έχει γίνει ακόμη κοινή ενιαία μηχανή με book manifests.
- Σελιδοδείκτες και θέση ανάγνωσης αποθηκεύονται τοπικά ανά browser / συσκευή, **χωρίς συγχρονισμό**.
- Η πρώτη εγκατάσταση και η πρώτη offline cache απαιτούν να φορτωθεί το site επιτυχώς.
- Η πλήρης browser end-to-end δοκιμή και δοκιμή εγκατάστασης σε φυσικό Android **δεν έχουν γίνει**. Ελέγχθηκαν η σύνταξη JS, δομή manifest, σύνολο αρχείων και τα ενσωματωμένα βιβλία.
- Μελλοντικές ενημερώσεις: αντικατάστησε τα αρχεία και αύξησε την έκδοση `CACHE_NAME` στο `sw.js`, ώστε να καθαριστεί το παλιό offline cache.
