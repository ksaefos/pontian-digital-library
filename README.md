# Pontian Digital Library v1.8.2 — Stable Reader

## Δημοσίευση στο GitHub Pages

1. Φύλαξε αντίγραφο του σημερινού repository.
2. Αντικατάστησε στο βασικό φάκελο **index.html** και **sw.js**.
3. Βεβαιώσου ότι στο repository υπάρχουν **manifest.webmanifest**, **library-data.json**, **PontianDL_Logo.svg**, **icons/** και **vendor/**. Τα αρχεία περιλαμβάνονται στο πακέτο· δεν χρειάζεται να τα ξανανεβάσεις εάν είναι ίδια.
4. Commit changes και έλεγξε την κανονική διεύθυνση GitHub Pages.
5. Έλεγξε σε ιδιωτικό παράθυρο browser και στη συνέχεια στο κινητό. Παλαιότερη εγκατεστημένη PWA μπορεί να χρειαστεί εκ νέου εγκατάσταση ή καθαρισμό cache.

## Αλλαγές

- Αποκαταστάθηκε το `<link rel="manifest">` στο κύριο HTML ώστε να μπορεί να αναγνωριστεί ως εγκαταστάσιμη PWA.
- Η μικρή οθόνη υποχρεώνει μονή σελίδα ανεξαρτήτως προηγούμενης ρύθμισης.
- Στο desktop χρησιμοποιείται ο σταθερός εγγενής renderer για μονή και διπλή διάταξη.
- Διπλό κλικ: επεξήγηση μέσα στη σελίδα **και** προσθήκη στο γλωσσάρι της αριστερής στήλης.
- Δεν ενεργοποιείται OpenPageFlip σε αυτή την έκδοση: η ενσωμάτωση παραμένει σε εκκρεμότητα μέχρι πραγματικά επιβεβαιωμένη δοκιμή. Τα vendor αρχεία παραμένουν διαθέσιμα στο πακέτο.
- Καθαρίστηκαν οι παλαιότερες σημειώσεις εκδόσεων.

## Σημαντικό

Δεν έχει ολοκληρωθεί πλήρης διαδραστική QA σε πραγματικές συσκευές. Η αποκατάσταση της δυνατότητας εγκατάστασης εξαρτάται και από HTTPS, σωστή εξυπηρέτηση των αρχείων, κριτήρια του browser και τυχόν εγκατεστημένη παλιά έκδοση. Η διόρθωση του manifest είναι αναγκαία, όχι από μόνη της εγγύηση εμφάνισης προτροπής εγκατάστασης.
