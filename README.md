# Pontian Digital Library — PWA v1.5.10

**Βάση:** το αυθεντικό ZIP v1.5.9 του χρήστη. **Όχι** η παλιότερη v1.5.5 ή v1.5.6.

## Σκοπός
Στοχευμένη αναθεώρηση της σελιδοποίησης για περιορισμό τεχνητών κατακόρυφων κενών και της παραμόρφωσης της τελευταίας γραμμής. Η ενσωματωμένη ελληνική υποστήριξη συλλαβισμού της 1.5.9 διατηρείται.

## Μεταβολές
- Καταργήθηκε η σκόπιμη μετατόπιση του σημείου αλλαγής σελίδας προς προηγούμενο τέλος πρότασης, που μπορούσε να θυσιάσει περίπου δύο γραμμές. Τώρα το κείμενο χωρά όσο περισσότερο μπορεί στην εκάστοτε σελίδα.
- Ο περιορισμός απομονωμένης τελικής γραμμής παρέμεινε, αλλά η μέγιστη οπισθοχώρηση μειώθηκε σε περίπου μία γραμμή.
- Περιορίστηκε το σταθερό κατακόρυφο περιθώριο ασφαλείας από 7–18px σε 3–7px, διατηρώντας μη μηδενικό περιθώριο για τα διακριτικά.
- Αποσαφηνίστηκε το CSS: φυσική τελευταία γραμμή με `text-align-last:auto`, αποφυγή αναγκαστικού stretch σε συνέχεια παραγράφου και μη αρχίγραμμα εκτός κλάσης `pdl-chapter-opening`.
- Διατηρήθηκαν αυτούσια το λογότυπο, τα εικονίδια, το manifest, και οι λοιπές λειτουργίες των δύο embedded readers.
- Cache key ενημερώθηκε σε `pontian-digital-library-v1.5.10`.

## Εφαρμογή
Στο GitHub repository αντικατάστησε μόνο `index.html` και `sw.js` από αυτό το ZIP. Άφησε ανέπαφα `icons/`, `manifest.webmanifest`, και `PontianDL_Logo.svg`.

## Αποτέλεσμα ελέγχων και περιορισμοί
- Τα δύο payloads αποκωδικοποιούνται και οι ενότητες περιεχομένου των βιβλίων συγκρίθηκαν byte προς byte με τη v1.5.9: **ίδιες**.
- Ελέγχθηκε η σύνταξη JavaScript και για τους δύο ενσωματωμένους readers μέσω `node --check`: **επιτυχία**.
- Τα άλλα assets είναι byte-identical με τη v1.5.9.
- **Η λειτουργική δοκιμή του HTML σε Chromium απέτυχε λόγω `ERR_BLOCKED_BY_ADMINISTRATOR` και δεν τεκμηριώνεται οπτικό αποτέλεσμα σε Android.** Δεν είναι αποδεδειγμένο ότι ο reader έχει αποκτήσει ισοδύναμη στοιχειοθεσία με Google Play Books.
- Οι τρεις φωτογραφίες περιλαμβάνουν πραγματικά τέλη κεφαλαίων/παραγράφων, όπου παραμένον κενά μπορεί να είναι αναπόφευκτα. Η CSS πλήρης στοίχιση δεν κάνει από μόνη της βελτιστοποίηση ολόκληρης παραγράφου (τύπου Knuth–Plass).

## Απαραίτητες πραγματικές δοκιμές
1. Σε τρεις συνεχόμενες σελίδες της «Σωνίτσας» έλεγξε απουσία υπερβολικών κενών και απώλειας λέξεων.
2. Έλεγξε τις λέξεις στο παλιό όριο «χρέιος / σ’ εσέν» σε ίδια γραμματοσειρά/μέγεθος.
3. Έλεγξε απλά τέλη παραγράφων, τις συνέχειες μετά το γύρισμα σελίδας και το μοναδικό αρχίγραμμα στην αρχή κεφαλαίου.
4. Έλεγξε σελιδοδείκτες, αναζήτηση και γλωσσάρι σε **αμφότερα** τα βιβλία.
5. Επανέλαβε με διαφορετικό μέγεθος γραμματοσειράς και μετά την εμφάνιση/απόκρυψη της εργαλειοθήκης.
