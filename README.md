# Pontian Digital Library PWA v1.5.9

Βάση: v1.5.8. Μόνη αλλαγή λειτουργίας: νέο λογότυπο PontianDL_Logo.svg σε αρχική βιβλιοθήκη, desktop & mobile reader, και PWA icons. Προστέθηκε αντίστροφη (λευκή) παρουσίαση του λογοτύπου στο θέμα `body.night`.

Για ενημέρωση GitHub Pages, αντικαταστήστε `index.html`, `sw.js` και `icons/icon-192.png`, `icons/icon-512.png`. Προαιρετικά ανεβάστε και το `PontianDL_Logo.svg` (είναι προ-αποθηκευμένο offline από το service worker, αλλά τα στοιχεία της διεπαφής είναι ενσωματωμένα στο HTML).

Οι δύο readers, συλλαβισμός, αναζήτηση, αποθήκευση θέσης ανάγνωσης, γλωσσάρι δεν τροποποιήθηκαν.
