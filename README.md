# Pontian Library Studio — εργονομική αναβάθμιση 2.4.1

Βάση: admin.html από το τελευταίο διορθωτικό πακέτο «References Safety Hotfix». Το πακέτο αλλάζει αποκλειστικά την διεπαφή του Studio, όχι το index.html, το library-data.json ή τον Worker.

## Εφαρμογή
Αντικατάστησε μόνο το `admin.html` στη ρίζα του repository (branch main). Κράτησε πρώτα αντίγραφο ασφαλείας του τρέχοντος `admin.html` και κάνε εξαγωγή JSON από το Studio, εφόσον έχεις μη δημοσιευμένες αλλαγές.

## Αλλαγές
- Σύνδεση από μικρό Login στην επάνω μπάρα. Συμπληρώνεις μόνο το επίθημα του Worker (π.χ. `xxxxx`) και κωδικό. Δημιουργείται το `https://pontian-library-sync.xxxxx.workers.dev`.
- Η φόρμα εξαφανίζεται μετά τη σύνδεση. Η κατάσταση φαίνεται με κόκκινη/πράσινη κουκκίδα στο header, στο πλάι και στην ενότητα «Σύνδεση & αντίγραφα».
- Η σύνδεση παραμένει ενεργή στη διάρκεια της ανοικτής καρτέλας και μέχρι την αποσύνδεση. Ο κωδικός διατηρείται μόνο στη μνήμη της καρτέλας και δεν αποθηκεύεται στη μόνιμη αποθήκευση του browser. Η ανανέωση απαιτεί νέο login.
- Η «Σύνδεση και φόρτωση» μετονομάζεται σε «Σύνδεση». Η πρώτη σύνδεση πρέπει να διαβάσει την τρέχουσα κατάσταση GitHub και να λάβει SHA για ασφαλή δημοσίευση· δεν χρειάζεται επανάληψη της φόρτωσης για κάθε publish.
- Η ενότητα «Αντίγραφα & εξαγωγή» συνδυάζεται με την κατάσταση σύνδεσης και τα κουμπιά GitHub.
- Η αναδιάταξη κεφαλαίων χρησιμοποιεί αριθμητικό select 01, 02, 03... Η μετακίνηση διατηρεί chapter ID και αποθηκεύει τη νέα σειρά τοπικά.
- Οι μαζικές εισαγωγές TXT ονομάζουν τα νέα κεφάλαια «Κεφάλαιο 01», «Κεφάλαιο 02» κ.ο.κ. ανεξάρτητα από τα filenames.
- Αριστερό μενού: «Επεξεργασία κειμένων».
- Οι ενέργειες προσθήκης βιβλίου μετακινούνται κάτω από τα βιβλία.
- Δεν αλλάζουν οι έλεγχοι ακεραιότητας ή η διαδικασία δημοσίευσης.

## Περιορισμοί
- Το login δεν είναι server-side διατηρήσιμη συνεδρία: επαληθεύεται ξανά με τον Worker μετά από refresh.
- Τα δικαιώματα επιτρέπουν δημοσίευση μόνο μετά από επιτυχημένη φόρτωση/σύνδεση και με ισχύον SHA.
- Δοκιμές σε πραγματικό Worker και παραγωγικό GitHub παραμένουν αναγκαίες, χωρίς να δοθεί ο κωδικός σε τρίτους.
