# Pontian Digital Library v1.5.5

Αντικατάστησε στο GitHub Pages τα `index.html` και `sw.js`. Δεν αλλάζει το manifest ή τα εικονίδια.

- Δεν γίνεται ποτέ εξαναγκασμένη πλήρης στοίχιση της τελευταίας ορατής γραμμής ενός αποσπάσματος.
- Το αρχίγραμμα επισημαίνεται ρητά (`pdl-chapter-opening`) μόνο στην πρώτη παράγραφο της πρώτης σελίδας κεφαλαίου.
- Οι παράγραφοι, τα βιβλία και οι σελιδοδείκτες παραμένουν ίδια.

Σημείωση: Το υπόλοιπο κείμενο μπορεί να συνεχίζεται στην επόμενη σελίδα, χωρίς να τεντώνεται η τελευταία γραμμή της προηγούμενης. Ο συλλαβισμός εξαρτάται από τον browser. Δεν έχει γίνει ακόμη έλεγχος σε πραγματικό Android.
